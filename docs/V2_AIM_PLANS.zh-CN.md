# V2 行为模式、Slot 参数、响应曲线与英雄例外

本文说明当前实现。各轮构建、自测与 CN 现场结果以 [实施进度](V2_PROGRESS.zh-CN.md) 和对应 Scenario 记录为准；连接成功不代表实际发射已验收。

2026-11-03 后续功能审计与 UI 调整记录：[审计报告](../../../04_SCENARIO/un-dma-v2/reports/aim-ui-audit-20261103/REVIEW.zh-CN.md)。修正动态 FOV 下的加权角度尺度、例外不限距离、独立运动配置初始复制、Shuwu 输出反馈、旧加速度参数范围，以及 Trigger 继承隐藏 Aim 例外的问题。

## 设置顺序

在自身英雄的瞄准 Slot 中，先设置范围与目标，再选择行为模式，最后调整当前 Slot 的行为、运动参数和目标英雄例外。模式管理页复用五种基础行为：Tracking、Flick、Flick2nd、Reacquire、Magnetic Trigger。旧的未命名方案显示为 Slot 自定义配置。

## 命名模式与独立参数

模式管理页可以新建、命名、编辑和删除模式，最多 64 项。模式定义基础行为、运动算法及首次使用时的默认参数；Slot 使用稳定模式 ID 引用，重命名不影响引用。被瞄准 Slot、全局配置或技能引用的模式不能删除，界面提示先更换模式。

每个 Slot 按模式 ID 分别保存参数；行为参数按基础行为保留，运动参数按算法编号保留。切换模式、行为或算法后再切回，恢复该 Slot 原值。模式结构修改会自动跟随；首次进入新的行为或算法采用模式默认值，已有调参不会被后续默认值覆盖。“恢复本模式默认参数”只重置当前 Slot 当前行为和算法。

两处使用同一套参数编辑器。模式可以保存时序、射击动作、速度、起步限制和分段参数；绑定、启用状态、选目标、FOV、骨骼、预测与英雄例外仍属于 Slot。运行中的模式结构变化会结束当前动作；自动蓄力遇到结构变化需松开辅助键后重新激活。

旧配置迁移时保留原有效运动与行为参数；旧命名方案若使用了不同算法的独立运动覆盖，迁为 Slot 自定义配置，避免迁移时改变算法。配置、快照、合并和自动保存共用已有通道。

## 误差响应曲线

新增算法编号 8“误差响应曲线”，旧编号 0–7 不变。Bezier 轨迹算法仍独立使用。曲线固定端点 (0,0)、(1,1)，两控制点坐标限制在 [0,1]，提供线性、平滑、快速响应、自定义、拖点、数值输入和恢复默认。

图形与运行调用同一求值器，先用牛顿迭代求 `Bx(t)=x`，必要时回退二分，再求 `By(t)`。当前角度误差长度 d、该候选实际有效角度 FOV R、现有速度强度 s 对应：`r=d/R`、`y=curve(clamp(r,0,1))`、`factor=clamp(s*y/r,0,1)`，再应用现有时间归一化、限幅、量化和输出。零误差或无效 FOV 不移动。

线性曲线保留 Linear 的速度含义；曲线直接面对真实目标，不叠加现有过冲曲线。解析顺序为模式结构与 Slot 参数、目标英雄运动例外、Flick2nd 显式第二阶段覆盖。第二阶段可选“继承”；旧配置原有显式算法继续保留。

## 通用松开发射

Flick、Flick2nd、Magnetic Trigger 共用“松开发射”开关：关闭时按下发射，开启时松开发射；手动射击策略仍禁止程序生成射击。新模式默认关闭，开启后默认手动按住射击键。

手动模式仅释放实际按住的射击键，需要设备支持物理按键监听和屏蔽，否则界面显示不可用。一次物理按下只允许辅助出手一次，必须真实松开再按下才能重试；切 Slot、切目标和目标端收到的程序松键都不会重置限制。物理键屏蔽一直保留到真实松键，避免继续按住时又蓄力。

自动模式使用独立辅助键并通过现有输出所有权按住射击键，按住即可蓄力，不依赖 FOV 内存在目标。“瞄准发射时机”有两个选项：

- 按住辅助键时：按住期间瞄准，达到蓄力与命中条件后释放；重复出手按基础行为节拍和连续射击设置，每轮重新蓄力。
- 松开辅助键后：按住期间只蓄力，松开后使用按下时捕获的 Slot 执行一次瞄准和释放，连续射击设置不会让这一动作重复。松开时没有可用目标就立即朝当前准心释放，不等待目标进入 FOV；达到“松开后瞄准上限”（默认 1000ms）也朝当前准心释放。

最低蓄力百分比与“无读数等待”均可配置；有效读数优先，等待时间只用于读数无效。读取失败与真实 0% 分开处理，不能把失败返回的零值当作有效 0%。本次 CN 154905N 半藏现场的蓄力读取不可用，实际采用已保存的 720ms 无读数等待；最低百分比在获得有效读数时才参与判定。无目标／瞄准上限的直接释放服从松键意图，不再等待最低蓄力。正常、延迟、强制射击共用解析后的动作，提交成功后才记录出手与冷却。

三个行为不再按 Hanzo 名称接管动作，也没有运行中的隐藏 65% 下限。旧 Hanzo 自动蓄力方案迁为显式的松开发射、自动蓄力、松开辅助键后执行，原有效最低蓄力与无读数等待写入配置；新模式和已保存的显式开关不受英雄名覆盖。蓄力读数和弹道数据仍在武器数据层。狂风箭应使用单独的按下模式或 Slot，程序不会自动改变开关。

停止、断连、换英雄、场景失效、超时、输出代次变化和抢占会清理所属按键及屏蔽状态。自动蓄力中止时松键可能让武器出手，需以实际武器效果验收。

## 选择规则

- 原来的最低 FOV、最低 HP、最近距离继续保留；最低 HP 使用绝对血量。
- “加权选择”将角度、距离、剩余血量比例分别归一化，按非负权重求加权平均，分数低者优先。归一化角度、距离上界在一次选择中统一，包含例外中的范围上界；距离不限时采用 500 米参考尺度。血量比例上界使用各目标可信最大血量。权重全零时按归一化角度选择。
- Any 不增加偏好条件。Prefer 在符合所有准入条件的候选中，先比较是否命中偏好，再比较组内分数；没有命中者时正常回退。
- Only 是硬准入条件。没有符合者就没有目标；指定英雄列表为空时不选择任何英雄。
- 偏好条件可以选择“指定英雄”“满血”“可见”。满血要求最大血量有效且当前血量至少为最大血量减 0.01 HP；不是根据英雄名称推测满血。
- 最低／最高 HP 是绝对血量限制，端点包含在内，最高 HP 为 0 表示不限。现有阵营、可见性／Trace、距离、FOV、实体身份和新鲜度约束仍然生效。
- 锁定的目标仍然有效时，先遵守最短锁定时间，再应用 Prefer。Only 或硬条件不通过时，锁定不能把它保留下来。组内沿用原有切换滞回；相同分数按稳定目标键决胜。
- 相同偏好组内保留既有规则：当前已在 FOV 内的候选优先于仅预测将进入 FOV 的候选。
- B.O.B 的旧动态记录没有可信英雄、HP 和可见性载荷，因此启用新偏好、HP 过滤或加权模式时，不从该旧记录补选目标。

## 一个 Slot，一套默认配置，加若干组例外

每组可指定一个或多个目标英雄，每个 Slot 最多 12 组，每个目标英雄只能属于一组。界面禁用已被其他组占用的英雄；加载畸形重复数据时，按保存顺序由第一组保留该英雄，修复重复或缺失的组 ID。

点击目标英雄选择框打开头像网格，按职责分组，支持英文名称与已有中文名称搜索、多选、清空选择；灰色头像悬停显示所属例外组。顶部自身英雄头像条右侧增加“浏览全部英雄”按钮。鼠标悬停头像条时，普通滚轮左右浏览头像，滚动本身不切换所编辑英雄；移出后仍按所在页面正常滚动。

例外未勾选的部分动态跟随当前默认配置；勾选覆盖时从当前默认值开始编辑，可以再取消覆盖恢复继承。支持三组覆盖：范围与 HP 限制、瞄点与预测、运动算法及其参数。例外中的范围覆盖采用固定 FOV；没有覆盖时继续使用 Slot 的固定／动态 FOV 设置。

添加英雄例外不改变 Only／Prefer 的英雄列表，也不改变 Slot 行为、火控、按键、开镜条件或启用状态。新增 Slot 仍复制参数、清空绑定、默认停用，例外也一起复制。

Trigger Slot 的偏好与 HP 条件独立保存，不借用另一个 Aim Slot 的例外。Trigger 保留自己的命中窗口选择逻辑，在窗口内应用偏好；专用技能消费者不启用 Aim Slot 例外。Aim worker 中的辅助选择入口仍检查当前上下文的 Only／HP 硬约束。

Flick2nd 继续保留身体接近、头部精修和第二阶段算法设置；例外瞄点参与候选获取，不能把固定的二阶段行为变成另一种行为。Reacquire 继续保留现有共享 Flick 路径，本轮没有新增独立的重捕获状态机。

## Shuwu 的 V2 适配

源公式来自研究目录的 `koi_shuwu.hpp`，原件未修改。产品内 `ShuwuCore.hpp` 保留公式，只补 C++20 配置比较；`AimShuwu.hpp` 负责工程单位和状态契约，不依赖研究目录。

- 原件处理像素误差；V2 适配使用每度 16 个虚拟误差单位。它们不是屏幕像素，也不是设备 counts。控制器输出仍是角度，既有输出层处理灵敏度、俯仰倍率、取整、队列和发送。
- 参考周期仍为 240 Hz；按实际样本时间换算步长，周期比例限制在 0.25～4。超过 100 ms 的间隔或时间倒退会重新开始；不会补算暂停期间的累计动作。
- 相同的非零样本时间不重复推进；优先使用微秒采样时间，缺少时使用已有位置／锚点时间的毫秒值。历史状态在目标身份、规则、算法、配置及既有 Reset／Hold 边界清理。
- X 轴对应 yaw、Y 轴对应 pitch，角度误差处理 yaw 环绕。输出在可选轴向抑制之后再次限幅，并受已有公共起步限制和输出保护约束。
- 历史补偿采用输出调用返回的成功命令：将取整后的设备命令换回角度，再换成参考周期的虚拟误差单位。失败、不发送或部分失败不当作完整成功。这里只知道提交结果，不是设备实际运动反馈。
- 软锁需要独立按键语义，V2 本轮没有建立这条绑定，因此不开放该功能；轴向抑制可以配置。
- 没有与 PID／Hybrid 叠加运行。Shuwu 的“积分”参数表示滤波运动补偿，不等同于普通 PID 积分。

配置继续经快照生效。松开后执行会保存按下时的 Slot 参数，结构变化取消该动作；新的默认值只用于首次使用或显式恢复默认。本轮不声称严格频率无关、性能领先、实战精度提高或已完成硬件验收。
