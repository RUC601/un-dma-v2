# V2 英雄资源与技能映射

2026-10-30：当前菜单 52 位英雄的默认 PC 技能位、大招及职业分类已逐项与 Counterpick Wiki 核对；重做内容结合官方补丁、OWLib 的精确 Loadout/TextureGUID 对应验证。[逐英雄清单](../../../02_RESEARCH/un-dma-research/v2-product-research/V2_ASSET_WIKI_CHECK.json)保留来源 URL、页面 SHA256、槽位和图像来源。

本轮纠正安燃、Domina、末日铁拳、回声、飞天猫、生命之梭、卢西奥、士兵76、秩序之光、托比昂、斩仇、探奇、破坏球、雾漾、禅雅塔的显示映射。瑞希、路霸、黑影的重做映射在此前补改中已纠正。回声黏性炸弹的新增配置默认按键改为右键，已有保存配置继续保留；查莉娅“低弹药右键”使用副攻击图标。

两个显示槽通常对应默认 Shift/E。堡垒和探奇没有常规 E 技能，第二槽分别显示战术手雷、钻头突刺（副攻击）；生命之梭按现代默认布局，安燃大招默认显示存活时的朱羽焚。核对清单记录这些例外。此处校正图标及默认 UI 定义，不代表逐英雄内存状态读取已经实测。

52 张 UI 头像保持原色，52 张 overlay 头像单独处理暗部及透明边缘；两者使用独立文件与缓存键。519 张技能图均为 stb_image 可解码的真 PNG。缓存清空后可重新加载；构建的 V2Assets 目标同步运行目录，包括仅改资源的情况。

已验证 Release 构建、623 个输出与运行目录逐文件一致，以及真实 stb_image / D3D11 WARP 解码、纹理创建、缓存隔离、清空后重载与全英雄离线显示。没有把上述检查当成融合器效果、现场状态或 Hitbox 验收。V1 未改，融合器效果和 ED 处理链按用户要求后置。
