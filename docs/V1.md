# V1 当前维护说明

2026-10-28 起，`01_PRODUCTS/un-dma-v1` 承接原 NE 仓库。产品称 UNDMA，地区称 CN；KR 指 Nexon，BZ 指普通国际服。本轮 V1 仍固定 CN，不增加地区识别、Steam 适配或候选配置回退。

## 使用

```powershell
cd D:\Desktop\SenseZen\ECS_O\01_PRODUCTS\un-dma-v1
.\build-release.ps1
.\build\Release\UNDMA_V1.exe --config-check
# 需要现场环境时，由使用者启动：
.\build\Release\UNDMA_V1.exe --test-server --test-server-port 19550
```

程序依赖同目录 DLL、info.db、assets、data 和 config，不能只移动 EXE。旧已用程序及全部旧 build 保存在 `06_ARCHIVE/un-unified-20261028/v1-before/build`。其旧缓存只供证据追溯，不能在新位置增量构建。

用户配置保持原格式，不因地区更名改动字段语义。活动配置位于 EXE 旁的 `config/`，包括 INI、heroes JSON、DMA 设备配置及用户预设；既有配置迁移逻辑保留。本轮离线检查在隔离副本进行，正式配置不作测试夹具。

## 构建与验证

普通 Release 不包含自测 CLI，保留编译开关 `UNLEASHED_TEST_SERVER` 与运行参数 `--test-server` 双门控。自测使用独立目录：

```powershell
.\build-release.ps1 -Tests
& 'C:\Program Files\Microsoft Visual Studio\18\Community\Common7\IDE\CommonExtensions\Microsoft\CMake\CMake\bin\ctest.exe' --test-dir .\build\selftests -C Release --output-on-failure
```

只做配置检查不会连接 DMA、启动 overlay 或发送 KMBox 输出。编译、自测与配置检查只能证明各自离线范围，不能代替 DMA、实体、画面、物理输出或长期稳定性验收。

- Runtime CN 锁定和 154504N 镜像门禁；World/BZ 只供继承自测，不得自动选入正式运行。
- 身份、scene、generation、100ms/13s 等原门控，以及输出释放、线程退出与资源关闭边界。
- Minimize Overlay 隐藏整层画布、最小化菜单，Home 热键和任务栏仍可恢复。普通 Home 关菜单保留画布；菜单打开后切到外部应用应收起整层；UN 自己的对话框不触发这一收起。
- 配置加载/迁移/保存一致；KMBox 和 TestServer 修改必须保留退出与只读/arm 边界。

offset 证明和只读探针归 `03_DOWNP/vertifytool`；运行接入归本产品；现场/视觉/遥测归 `04_SCENARIO`。新偏移必须先有静态/source 证据和只读语义验证，不能由非空指针、自测或历史注释代替。

## 版本与恢复

Git 迁前节点为 `baseline/v1-before-unified-20261028`；本轮验证节点记录在总进度及证据中。V1 分支 `v1/cn`、V2 分支 `v2/framework`，各有独立源码工作目录、build、配置、日志和产物，共享 Git 对象历史。不要 reset、checkout、clean 或覆盖另一工作区来切换版本。
