# V2 模型形状绘制

2026-10-30：产品ID表60类英雄/训练实体均已导出球体/胶囊资料，79个模型集合、1827条形状已接入正式V2。部分集合为子模型/道具，不能据此推断所有变形已覆盖。

显示页“模型形状（研究）”沿用 draw_hitbox。数据来自 OWLib CN 客户端154461N/清单154088，源参数与未知层字段保存在 `../../02_RESEARCH/un-dma-research/v2-hitbox-implementation-20261030/batch-heroes/`；猎空原始资料保留原目录。没有把全部重叠层认定为伤害Hitbox。

实现位于 `include/Game/ModelShapes.hpp`、`HeroModelShapes.inl`、Entity.hpp、EntityReader.cpp 与 EntityVisuals.cpp 的 DrawHitboxes。模型按英雄ID和骨骼ID交集选择身体候选，绑定ID查表得到运行时索引，不直接用ID作为数组下标。相同最高交集保持未解析；小道具骨骼集合不作为身体。未匹配模型沿用旧估计几何；已匹配模型缺失的骨骼跳过对应形状，其余部位继续显示。

开关启用时，现有scatter读取完整0x30骨骼记录块；候选布局为四元数+0、缩放+0x10、平移+0x20。姿态随实体快照发布，检查bonedata身份与100ms新鲜度；渲染线程无设备读取。球体/胶囊局部3D线段按SQT→人物Y旋转/平移→相机投影；原始形状显示尺寸不经过瞄准窗口百分比缩放。UN瞄准/触发/Behavior参数不改。

正式Release、配置检查和专项CTest通过。79集合107108条线段的表面距离、SQT、ID查找与皮肤附加骨骼选择已检查。9809本机实际看到实体线框，现场当前身体绑定：死神24/24、托比昂42/42、安娜25/25、奥丽莎41/41、拉玛刹32/32；黑影28/29、索杰恩12/24。原始形状SQT读取实际有随时间变化的旋转与位置。没有主机9808画面对照，姿态/空间准确性和伤害语义待逐项验证。
